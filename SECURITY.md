# Security

Please don't report security problems in public issues.

Use GitHub's private vulnerability reporting instead: open the repository's
**Security** tab and choose **Report a vulnerability**
([direct link](../../security/advisories/new)). Only the maintainers can see the report.

Useful details include the affected server or tool, the client and OS, steps to
reproduce, and what an attacker could achieve (for example, reading files outside the
configured folders, or making a server reachable from the network).

Problems in the third-party servers (markitdown, Git, filesystem, Playwright) or in
ComfyUI belong with those projects. If the issue comes from how this repository tells
people to configure them, report it here.
